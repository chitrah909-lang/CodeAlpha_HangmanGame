# Hangman Game 🎮

## Description
A simple text-based Hangman game built using Python. The player guesses a hidden word one letter at a time with a limited number of incorrect attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Tracks correct and incorrect guesses
- Displays remaining attempts
- Win/Lose messages

## Technologies Used
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run:
   ```
   python hangman.py
   ```
